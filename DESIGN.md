# Дизайн-система портфолио

Один файл `index.html`, inline CSS+JS, без сборки. Любая правка — внутри этих правил.
Если правка их нарушает — менять правила здесь, а не делать исключение в коде.

## 1. Цвет — только чёрный, белый, серый

Ни одного оттенка (hue) в интерфейсе. Глубина берётся из **значения** и **волосяных линий**,
не из цвета. Токены в `:root`:

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0A0A0A` | фон страницы |
| `--surface` | `#101011` | карточка в покое |
| `--surface-hi` | `#17171A` | карточка под курсором |
| `--line` | `#232326` | волосяная линия в покое |
| `--line-hi` | `#3C3C42` | волосяная линия под курсором |
| `--ink` | `#F5F5F5` | основной текст |
| `--ink-2` | `#A9A9B0` | вторичный текст, описания |
| `--ink-3` | `#6E6E76` | подписи, лейблы, URL |
| `--ink-4` | `#4A4A52` | самый тихий уровень, номера секций |

**Единственный цвет на странице — внутри скриншотов клиентских сайтов.** На десктопе они
лежат в `grayscale(1)` и наливаются цветом под курсором. На телефоне (`hover:none`) —
сразу в цвете: там это инструмент показа, а не витрина.

Запрещено: золото, зелёный «live», любой акцент с hue. Статус `LIVE` — белая точка.

## 2. Типографика

- **Inter** 300/400/500/600 — всё.
- **Instrument Serif italic** — ровно одна фраза в H1. Больше нигде.
- Заголовки: `letter-spacing` от `-.032em` до `-.035em`, `font-weight:600`.
- Тело: `font-weight:300` для длинных абзацев, `line-height:1.55`.
- Лейблы и бейджи: uppercase, `letter-spacing` `.11em`–`.24em`, 10–12px.

## 3. Движение

Одна кривая на весь сайт:
- `--ease: cubic-bezier(.22,.61,.36,1)` — состояния (hover, цвет, бордер)
- `--ease-out: cubic-bezier(.16,1,.3,1)` — появления и смещения
- `--t: .45s` — интерфейс · `--t-slow: .75s` — изображения

Правила:
- **Никакого IntersectionObserver.** Ревил — rAF-throttled sweep по `getBoundingClientRect()`.
  Условие — только `top < vh*0.9`, **без** проверки `bottom`: иначе блок, проскочивший между
  кадрами или открытый по якорю, навсегда зависает на `opacity:0`.
- Пересчёт свипа обязателен на `scroll`, `resize`, `orientationchange`, `load` и на `load`
  каждой картинки — ленивые скриншоты сдвигают раскладку.
- Соседи в одной сетке появляются каскадом: `--d` = индекс × 80ms, потолок 5 шагов.
- `prefers-reduced-motion` — всё видимо сразу, счётчики не запускаются.
- Горизонтальный скроллер навигации двигать через `nav.scrollLeft`, **не** `scrollIntoView()`:
  последний достаёт до документа и способен оборвать плавный переход по якорю.

## 4. Раскладка

- Контент: `max-width:1200px`, паддинг 28px (20px на телефоне).
- Карточки: **всегда две колонки** — `repeat(auto-fit, minmax(420px,1fr))`.
  Трёхколоночную сетку не вводить: четыре карточки ложатся 3+1 и ломают ритм.
- **Нечётное число карточек в секции** → первой ставить `.card.lead`: она растягивается
  на всю строку (`grid-column:1/-1`), и остаток делится ровно надвое. Орфанов не остаётся.
  Лид — самая свежая или самая сильная работа секции, не случайная.
- Высота превью: 310px (десктоп) → 270px (≤900px) → 216px (≤640px).
  У `.card.lead` — 480px, но только от 901px: на телефоне лид ничем не отличается от прочих.
  Высоту лида подбирать по содержанию скриншота: нижний край не должен резать
  ключевой элемент сайта пополам.
- Скриншоты — WebP, `width`/`height` в разметке, `loading="lazy"`, `?v=N` в адресе.
  **При замене картинки поднимать `v`**, иначе у клиента останется старая из кэша.

## 5. Содержание

- В первых трёх секциях — **только живое**. Нет живой ссылки → работа идёт в «Built, not published» без ссылки.
- **Никаких личных контактов** в файле: ни телефона, ни почты, ни мессенджеров.
- Каждое число в шапке (9 / 7 / 5) должно сходиться с фактическим числом карточек ниже.
  Сейчас: 9 живых · 7 автомобильных · 5 в Аль-Куззе (Grand Power, Milad, Future Tires,
  RR Tire, Shawarma Hut). Добавил работу — пересчитай все три.
- Не размечать `aggregateRating` / `Review` в JSON-LD: рейтинги собраны Google, это спам по их правилам.
